    [07]Questions
    Questions
    
    
    
      
    
        How do I push, or open a pull request?
        
    From the task: Push Branch… pushes its branch under a readable name (never forced), and Open Pull Request opens your host's page for it in the browser (GitHub, GitLab or Bitbucket). Noon uses your own Git credentials and never signs in to your host. Or merge locally: Merge adds a merge commit with only the task's commits, running your repository's hooks as git merge would.
    
      
    
      
    
        Can I add a folder that does not use Git?
        
    Yes, on your Mac. Add your project folder and Noon offers to set up version control. Review the files, exclusions and Git identity, then choose Set Up and Add to create the first commit. Setup stays on that computer; no Git remote is added and nothing is pushed.
    
        
    Choose a project folder, not an entire home folder, disk or protected system/account folder. Git and read/write access are required, and setup refuses folders containing more than 1,000,000 files and folders.
    
      
    
      
    
        Which agents does Noon work with?
        
    Claude Code, and Codex 0.160.0 or later. Noon shows their reads, edits and approval requests. Other command-line agents, such as Gemini CLI and OpenCode, can run in a task's terminal, and the map follows the files they write.
    
      
    
      
    
        Is a task's workspace a sandbox?
        
    No. A workspace is a Git worktree, a separate checkout of your project. An agent can reach any files its permission settings allow, so review its approval requests.
    
      
    
      
    
        Why macOS 27?
        
    Noon is built and tested on macOS 27 on Apple silicon, so that's what it claims today. It is built to run on macOS 14 and 15 too, and will say so once it has been tested there on real Macs.
    
      
    
      
    
        What else do I need?
        
    Git from Apple's Command Line Tools, which Noon offers to install, and Claude Code or Codex, installed and signed in. Noon's window needs at least 1120 × 720 points, and it has a dark appearance only.
    
      
    
      
    
        Is Noon open source?
        
    No. Noon is free to use for personal or commercial work, but its source isn't public. The license has the details.
