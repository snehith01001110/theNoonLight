Classification model

Do not treat every label as an equal tag. Every venue is understood through three different dimensions.

1. Primary Type

What kind of establishment is this? Usually one canonical core identity.

  • Cocktail Bar
  • Dive Bar
  • Wine Bar
  • Beer Bar
  • Sports Bar
  • Pub
  • Lounge
  • Nightclub
  • Brewery / Taproom
  • Winery / Tasting Room later

2. Setting

Where/how does the place physically exist? Factual descriptors can combine.

  • Rooftop
  • Hotel
  • Restaurant-attached
  • Waterfront
  • Outdoor / Garden
  • Basement
  • Historic
  • Vineyard / production premises

3. Experience

What is it actually good for? Primarily derived from aggregated recent visitor signals.

  • Date night / Groups / Celebration
  • Conversation / Low-key / Lively
  • Dancing / Live music
  • Late night / After-work
  • Great views
  • Worth the $$$
  • Easy walk-in
Example: Charmaine's can be Primary Type: Cocktail Bar + Settings: Rooftop, Hotel + community-derived Experiences such as Great views, Groups, Date night. This avoids incoherent flat-tag combinations while preserving useful nuance.
