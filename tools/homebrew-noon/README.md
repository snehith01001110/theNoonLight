# homebrew-noon

The Homebrew tap for [Noon](https://thenoonlight.com), which runs coding
agents side by side on a live map of your code (Mac, Apple silicon, macOS 27
or later).

```sh
brew install --cask snehith01001110/noon/noon
```

Noon updates itself (it asks first), so `brew upgrade` leaves it alone
unless you pass `--greedy`. Downloads and release notes:
[noon-releases](https://github.com/snehith01001110/noon-releases/releases).
